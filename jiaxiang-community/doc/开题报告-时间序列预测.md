# 开题报告（答辩稿）

## 一、课题研究的目的和意义

  时间序列预测是智能决策系统中的基础能力，直接服务于电力调度、交通治理、气象预警、金融风控与工业运维等关键场景。随着物联网与业务系统的持续数字化，观测频率不断提高、预测跨度持续拉长，模型不仅要在短期范围内拟合局部波动，更要在长预测步条件下稳定表达趋势漂移、周期演化与跨变量耦合关系[1-3]。从工程实践看，预测误差已不只是算法指标问题，而是与资源分配、风险处置和公共服务质量直接相关的治理问题[4-5]。

  现有方法虽已从统计模型发展到深度模型，再到预训练基础模型，但“长序列、多变量、强噪声、非平稳”这一现实组合仍使模型面临学习目标混杂与泛化不稳的双重压力[6-8]。例如在电力与交通任务中，节假日冲击、气象突变与行为切换常导致相位错位与频率偏移；在工业传感与运维任务中，漂移、异常点和采样噪声又会放大远期预测误差[9]。因此，如何把“可预测的结构信息”与“不可预测的随机扰动”有效分离，并在时域与频域之间建立互补建模机制，是提升长序列预测可靠性的核心问题[10]。

  本课题拟围绕“结构化分解 + 时频协同 + 鲁棒融合”构建可解释、可迁移的长序列预测框架：在分解层面显式刻画趋势、季节与残差成分；在建模层面分别设计针对性的时域/频域分支；在融合层面引入相位对齐与自适应频带权重，以提升长预测步和多变量场景下的稳定性。该研究不仅可补足现有方法在残差建模与频带解释方面的不足，也有望为实际业务提供更可信、更可诊断的预测依据。

## 二、国内外同类课题研究现状及发展趋势

  从研究脉络看，国内外时间序列预测已由“统计假设驱动”逐步转向“表示学习驱动”，并在近两年进入“结构先验与基础模型并行推进”的新阶段。早期 ARIMA、指数平滑与状态空间方法强调平稳性和参数可解释性，适合小规模、单变量和短期预测；但面对高维长序列与复杂扰动，其线性假设与人工建模成本逐步暴露瓶颈。深度学习阶段通过 CNN、RNN、TCN 等提升非线性拟合能力，却仍受限于长程依赖衰减和多尺度模式耦合。Transformer 体系将全局依赖建模推向新高度，但其在长序列中的计算代价、噪声敏感性和解释不足问题也随之凸显[11-13]。因此，当前研究共识已从“单一主干网络更强”转向“结构化建模更稳”，即通过分解、混合与对齐机制降低学习目标冲突。

  在“结构化分解与多尺度混合”方向，2024 年以来的代表性工作进一步证明：对时序成分进行显式组织，往往比单纯加深网络更有效。TimeMixer 通过 Past-Decomposable-Mixing 与 Future-Multipredictor-Mixing 在多尺度上处理趋势与季节信息，体现出“分而治之”的设计优势[1]；TEMPO 将趋势、季节、残差先验与提示机制结合，说明结构归纳偏置对预训练模型同样重要[2]；FITS、CARD 与线性映射类研究则从频域插值、通道对齐和简洁映射角度证明“轻结构 + 强归纳”在长预测步上具有竞争力[3-5]。进一步看，Pathformer、Skip-Timeformer、SparseTSF 等方法通过自适应路径、跳时交互与稀疏建模压缩冗余计算，反映出该方向的一个共同趋势：在保证表达能力的同时追求复杂度可控与部署友好[14-16]。这也提示后续研究不能只比较精度，还应同时评估计算开销、参数效率与鲁棒稳定性。

  在“多变量关联与外生信息融合”方向，研究重点正由时间维度长依赖扩展到变量维度关系重建。iTransformer 通过将注意力主轴转向变量维度，显著增强跨变量依赖建模能力[6]；TimeXer 面向外生变量引入 patch-wise 自注意与 variate-wise 交互注意，改善了内外生信息对齐问题[7]；UniTS 尝试统一预测、分类、补全、异常检测等任务，展示了任务共享表示的可行性[8]。此外，TFformer、PMformer 与 SAMformer 从时频双向注意、Informer 改进架构与优化策略层面继续提升多变量任务表现[17-19]。但需要指出的是，多变量建模并不等于简单拼接变量：当变量之间存在不同采样噪声、相位偏移和传播时滞时，若缺少显式对齐机制，模型容易学习到“统计相关但因果弱”的伪关系，进而在跨场景迁移中出现性能坍塌。这一问题在工业与城市运行数据中尤为突出，也成为当前模型由“高分数”走向“高可信”的关键门槛。

  在“时频融合与非平稳鲁棒”方向，频域建模已从辅助特征提取发展为核心建模手段。大量工作表明，傅里叶域或小波域可以更高效地表达长周期结构，并在长预测步下降低误差累积[9,20-21]。频率自适应归一化与鲁棒训练方法进一步说明：面对分布漂移、异常点和噪声污染，仅靠时域拟合难以维持稳定性能，必须将频率偏移与幅值畸变纳入模型设计[11-12]。与此同时，TimeMachine、CALF 等工作把状态空间建模与跨模态对齐引入预测任务，拓展了时序建模的工具边界[22-23]。从发展趋势看，时频协同已经从“可选增强模块”转向“长序列稳定预测的必要组成”。但现有方法中仍普遍存在频带划分偏硬、相位信息利用不足的问题，导致模型虽能识别“是否有周期”，却难解释“周期为何变化、变化由何成分主导”。

  在“时序基础模型与预训练范式”方向，2024—2025 年进入快速迭代期。Time-LLM 通过重编程机制复用语言模型能力，显著提升少样本场景下的可迁移性[15]；Timer、TimesFM、Moirai、MOMENT、Chronos 与 Tiny Time Mixers 分别从生成式预训练、解码式基础模型、通用 Transformer、开源模型族、离散化建模与轻量化部署推进跨领域预测能力[16,24-28]；Moirai-MoE 进一步以稀疏专家机制提升模式专门化表达[29]。2025 年后，TimeMixer++、Sundial、In-Context Fine-Tuning、VisionTS 等工作将研究重心推进到多任务统一、上下文快速适配与跨模态迁移，显示“通用时序分析”正在取代“单数据集最优”成为新的评价目标[30-33]。然而，基础模型路线也带来新的挑战：第一，模型规模扩张提高了部署门槛；第二，跨域泛化提升并不自然等价于单任务可解释性增强；第三，在高噪声业务数据上，预训练先验与具体任务偏差之间仍缺少稳定的校准机制。

  从国内外研究对比看，国际研究在大规模预训练、统一基准和开源生态方面推进更快，强调“模型通用性 + 工程复现性”；国内研究则在场景驱动优化、轻量化结构和行业适配上形成明显优势，特别是在电力、交通、工业互联网等任务中更关注“可落地、可维护、可解释”。两者正在形成互补：一方面，国内场景提供了高价值真实问题与复杂约束；另一方面，国际基础模型与开源框架为方法迁移提供了技术底座。未来趋势很可能是“基础模型能力下沉 + 场景结构先验上浮”，即以通用表示为底层，以任务结构化分解为上层，实现性能、效率与可信性的统一。

  进一步从方法论层面归纳，近两年研究已出现三条趋同路径。其一，模型设计从“黑盒端到端拟合”转向“成分可分解、路径可追踪”的白盒化趋势，强调趋势、季节、残差和噪声的职责边界；其二，训练目标从“单一步长误差最小化”转向“多尺度一致性 + 分布稳健性”的复合目标，关注长期稳定而非短期最优；其三，评估体系从“平均误差指标”转向“精度—鲁棒—效率—解释”多维度评价。这些变化说明，时间序列预测正在从算法竞赛式迭代走向工程系统式升级，研究问题也从“能不能预测”转为“能否在复杂场景持续可信地预测”。

  面向“标准开题答辩”的研究评述逻辑，还需要进一步回答一个核心问题：为什么在已有大量 SOTA 模型的情况下，课题仍有必要开展？从文献证据看，现有高性能模型在公共数据集上的优势，往往建立在相对稳定的采样机制与较一致的评测协议上；一旦进入真实业务系统，数据存在异构采样、缺失补齐、节律突变与外部事件冲击，模型排名会发生明显变化[10-12,23]。这意味着“榜单领先”并不直接等于“生产可用”，研究者必须把问题从“模型是否更复杂”转向“结构是否更匹配数据机理”。以电力负荷为例，工作日与节假日在频率能量分布上差异显著，若仍采用统一频带处理，模型会把节律切换误判为噪声；以交通流量为例，早晚高峰位置并非固定平移，而是受天气、事故、管制等因素影响产生相位漂移，若缺少显式对齐，远期预测会出现峰值提前或滞后；以工业监测为例，设备老化导致趋势项缓慢偏移，而突发异常带来高频尖峰，若不区分“可学习变化”与“异常扰动”，模型会在鲁棒性与灵敏度之间失衡。由此可见，当前研究真正短板不在“是否引入了 Transformer 或基础模型”，而在“是否形成了可解释的成分责任分配与可诊断的误差来源闭环”。
  基于上述判断，国内外研究正在出现“从单模型性能竞争到任务系统建模竞争”的新动向：一方面，基础模型通过统一预训练提升跨域迁移下限，解决“冷启动难、样本少、场景多”的现实痛点[24-33]；另一方面，任务侧模型通过结构化分解、轻量化适配和在线校准机制，提高在特定行业中的稳定上限[1-9,14-22]。这两条路线并非替代关系，而是“底座能力”和“场景能力”的分工协同。未来可预见的发展趋势包括：第一，数据侧将更加重视时序质量治理，训练前的数据清洗、缺失修复与异常标注将与模型训练共同优化；第二，模型侧将更强调可插拔模块化，便于在不重训大模型的前提下完成行业定制；第三，评估侧将引入更多风险导向指标，如极端误差、峰谷偏移、异常期稳定性和可解释一致性，而不再仅依赖 MAE/MSE 等均值指标；第四，部署侧将推动“云边协同 + 轻量推理”，要求模型在资源受限环境下保持预测质量。对本课题而言，这一趋势直接指向研究价值：不是重复提出一个更深网络，而是围绕长序列难点构建“分解明确、融合合理、诊断可追”的技术路线，使模型在真实复杂场景中既有精度，也有稳定性与可解释性。
  但就现阶段而言，关键缺口仍然清晰存在：一是二分解框架仍常将高频有效信息与异常噪声共同压入季节项，导致学习目标被污染；二是大量模型虽引入频域模块，却缺少对相位偏移与频带语义的细粒度建模，远期周期表达稳定性不足；三是基础模型关注跨域泛化，但对单任务内部的成分贡献、误差来源与决策可解释链条支持不够。基于上述缺口，本课题将以“趋势—季节—残差三分解”为起点，结合时域局部动态与频域全局周期的双分支协同，并通过相位对齐与自适应频带融合实现鲁棒预测；最终形成“可解释分解—可对齐建模—可诊断融合”的创新技术路线，为复杂长序列预测提供更具工程可信度的方案[34-38]。
